# JW Climatização MCZ

Landing page da JW Climatização MCZ: limpeza e instalação de ar-condicionado split em Maceió, no litoral de Alagoas e em Arapiraca.

- `index.html`: página principal.
- `privacidade.html`: política de privacidade (LGPD).
- `img/`: fotos dos serviços.

É uma página estática em HTML, CSS e JavaScript, que usa GSAP e ScrollTrigger para as animações. Para ver no computador, abra o `index.html` no navegador ou rode `python3 -m http.server` nesta pasta.

Esta é uma versão de rascunho: as duas páginas têm `noindex` e não aparecem no Google até a aprovação.
